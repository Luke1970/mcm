Mail Commander (mcm) @VERSION@ - console mail client.

-Supports imap(s) pop3(s), maildir, mbox and MH mailstore formats, and reads
 Dovecot sdbox.
-Can be fully controled by keyboard, has limited mouse support.
-Can handle long lists of emails and display large emails, more info under
Limitations..
-[WARNING] Can remember passwords encrypted. Never use this if you're not 
convinced of the safety/ security of your home folder!
-Minimum window size is 80x25.
-Program was tested for Imaps on Linux, OpenBSD, Netbsd, and Windows.
-This program was fully build with Claude AI, based on the knowledge and hard
labour of many people. A small thank you is listed at the end of this file.

The source of this program is licensed under GPLv3.

Usage:
  mcm                       the only account, or choose one from a list
  mcm [options] [WHERE]     WHERE says where the mail is (see below)

Options:
  -a NAME     use account NAME from the config file (a new one if unknown)
  -n          set up a new account (asks: IMAP, POP3 or local mail)
  -f WHERE    where the mail is; the same as giving WHERE on its own
  -s SERVER   IMAP/POP3 server host name
  -p PORT     port (default 993 for IMAP, 995 for POP3)
  -u USER     login name
  -t THEME    color theme: a name (~/.config/mcm/NAME.theme) or a file
  -V          version
  -h, --help  this text

An account with the same server and user (or path) is used, or a new one is
made and kept in ~/.config/mcm/mcm.conf. Passwords are never taken from the
command line; they are asked for, and can be stored encrypted.

WHERE - the kinds of mail mcm reads:

  IMAP over TLS - mail and folders stay on the server.
    imaps://[USER@]HOST[:PORT][/FOLDER]            (port 993)
      mcm imaps://jan@imap.example.com
      mcm imaps://jan@example.com@mail.example.com:993/Archive/2025
    The user may be an e-mail address: the last '@' ends it.

  POP3 over TLS - INBOX is read from the server and left there.
    pop3s://[USER@]HOST[:PORT]                     (port 995)
      mcm pop3s://jan@pop.example.com
      mcm pop3s://jan@example.com@mail.example.com:110   (110: STLS required)
    Sent, Drafts and other folders are local, in ~/.local/share/mcm/ACCOUNT/;
    seen/answered marks are kept there too. F5 checks for new mail.

  Maildir - a directory with cur/ new/ tmp/, one file per message;
  subfolders are .Name directories inside it (Maildir++).
      mcm ~/Maildir
      mcm maildir:/home/jan/Maildir

  mbox - one file holding many messages, each starting with a "From " line.
      mcm /var/spool/mail/jan
      mcm mbox:~/mbox
    It is only read and appended to; messages read count as seen until exit.

  MH - a directory of numbered message files (1, 2, 3 ...), with the
  unseen/replied/flagged lists in .mh_sequences; subdirectories are folders.
      mcm ~/Mail/inbox

  sdbox - Dovecot's single-dbox: mailboxes/NAME/dbox-Mails/u.1, u.2 ...
      mcm ~/sdbox
    Only read: flags come from Dovecot's index, "seen" set in mcm lasts
    until exit; nothing is copied into, moved or deleted. mdbox cannot be
    read (use Dovecot's IMAP, or doveadm sync to Maildir).

  A directory of folders - every Maildir, mbox file and MH folder under it
  becomes a folder (subdirectories nest); $MAIL is INBOX if none is found.
      mcm ~/Mail
      mcm file:///home/jan/Mail

  A local path starts with '/', '~' or '.', or with file://, maildir: or mbox:.
  In local folders and POP3 accounts, Sent and Drafts are made when first used.

Keys (? in mcm shows them all, F1 opens the menu):
  Tab           left window: emails, folders, accounts      Enter  open
  Left / Right  move between the windows
  PgUp/PgDn     page the list       Space / Shift-, Ctrl-, Alt-Space or
                                    Backspace: page the message (down / up)
  M R F         Mail, Reply, Forward (vim-like editor)
  H W X         all headers, wrap long lines (or scroll sideways), hex
  S P T         save the message to ~/Downloads, print it (lp), attachments
  T             in the editor: attach a file (an Attach: line per file)
  A             accounts            C  config (SMTP, wrap width, passwords)
  L             filter the email list on subject or sender (Esc: all again)
  F5            new mail            Q  quit
  Ctrl-Q        quit at once, from anywhere (a message being written is
                saved in ~/.local/share/mcm/unsent-DATE.txt)
  Ctrl-C        the same, also while mcm waits for the network;
                a second Ctrl-C leaves immediately

Files:
  ~/.config/mcm/mcm.conf        accounts and settings (mode 0600)
  ~/.config/mcm/NAME.theme      colors, read at every start
  ~/.config/mcm/certs           certificates you chose to always accept

In mcm.conf, editor = PROGRAM is used when $VISUAL and $EDITOR are not set
(else vi; Windows Notepad); pdf_viewer = PROGRAM opens PDF attachments and
html_viewer = PROGRAM web links (else the desktop's program, xdg-open).
