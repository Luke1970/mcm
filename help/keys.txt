# Key list shown by ? (or the menu's Help > Key list) in mcm. Edit it, then run make (see cmdline.txt).
Mail Commander (mcm) @VERSION@ - console mail client

Author: Lucien van Lint - mcm@sc00by.nl
Co-author: Claude Code

MCM basically has 4 windows. From left to right:
Accounts | Folder list | Email list | Email body

Basic usage:

In a terminal with 80 characters width, only the email list (Folder INBOX) 
and the window with the Email body (Message) will be shown. When expanding 
the width of the terminal, also the Folder list will appear and when 
expanding more also the window with accounts will show.

Tab                  When not all windows are shown, TAB will cycle
                     the left window with the missing windows. Tn the 
                     example above the list of emails, can be replaced 
                     with the list of mail folders and the list of 
                     accounts by pressing TAB
Left / Right         Selects which window is focused, and makes the 
                     left window alternate with windows not shown.
Up / Down            move selection / scroll message 
PgUp / PgDn          page through the message list
Space                page down in the message (from every window)
B                    page up in the message (in the message window)
:                    vim-like command in the message window:
                     :e         the message in $EDITOR (vim -R, read only)
                     :q         quit mcm (also :q! :qa :x :wq)
                     :w [FILE]  save the message (no FILE: as S), :w! replaces
                     :N :+N :-N :$   go to line N, N lines on/back, end
                     :/text :?text   search on / back (any case),
                                     matches highlighted until :noh
                     :set wrap  :set nowrap  :hardcopy (print)  :h (help)
Shift-/Ctrl-/Alt-Space, Bksp
                     page up in the message Many terminals and 
                     desktop environments have reserved Shift-Space or
                     convert it with Space. Use Ctrl-Space, Alt-Space 
                     or Backspace as a alternative)
Home / End           first / last
Enter                open folder; in the list with emails: select the
                     message (or unselect it) and go to the next one
Shift-Enter          select from the last message Enter selected to
                     this one (in terminals that report Shift-Enter)
Shift-Up / -Down     select the message and the one above / below
Esc                  back to message list; in the list: leave the
                     filter, else clear the selection

Selections available for Message window, 
as shown on bottom of window H W X S P T K:
                     H  Toggle between all headers and short header info
                     W  wrap/unwrap long lines.
                     X  switch between hex dump and regular view.
                     S  save the message as shown in ~/Downloads
                        (or ~): mcm--FROM--DATE--SUBJECT.txt
                     P  print the message (lp)
                     T  attachments: open one (in the desktop's
                        viewer) or save it in ~/Downloads
                     K  links in the message (the [n] numbers and
                        written-out web addresses): choose with
                        Up/Down or type the number, Enter opens it
                        in the browser. In the message window Enter
                        or a number opens this list too (12 Enter:
                        link 12). The attachments follow the links:
                        Enter on one asks Open or Save, as T does
Up / Down            in the message window: to the previous / next
                     link or [Attachment: ...] on the screen (they
                     are underlined, the chosen one shown as
                     >link<), else scroll; Enter opens the link or
                     asks Open/Save for the attachment, Esc leaves
                     it. A mouse click on one does the same

Selections available for list with emails:
                     L  Shows filter. Enter keyword, press enter.
                        Esc leaves filter.
                     O  Opens a window with the selected messages
                        (none selected: the one under the cursor):
                        flags, subject, from, date/time, size.
                        C  copy them to a folder
                        M  move them to a folder
                        D  delete them (move to Deleted Items;
                           in Deleted Items: for good)
                        Enter  unselect one   Esc  close
                     U  Undo the last copy, move or delete (asks
                        first; shown on the border while possible)

M R F (T)               Mail / Reply / Forward (opens the editor;
                     T there attaches a file)

A  Account           switch account, name, full name, password
C  Config            SMTP, account, wrap width, theme, passwords
Ctrl-← / Ctrl-→      narrower / wider left column (or drag the border)
F5                   refresh folder (new mail)
Ctrl-L               redraw screen
F1 / F10             the menu: every command in six columns (MCM,
                     Account, Folders, Emaillist, Email, Help);
                     Left/Right column, Up/Down item, Enter runs it;
                     a highlighted letter (or /) runs its item from
                     any column; Esc closes the menu.
                     Folders: creaTe, Delete, reName, moVe work on
                     the folder the folders window points at
?                    this key list
Q                    quit
Ctrl-Q / Ctrl-C      quit at once, from anywhere (also in dialogs and
                     the editor; text being written is saved in
                     ~/.local/share/mcm/unsent-DATE.txt). Ctrl-C also
                     stops when program is not waiting for keyboard
                     input.
Mouse                click the list's bottom border to filter
                     (Esc=Leave there ends it);
                     click an email or folder to select it, double
                     click to open it; click a menu bar item, L on the
                     list border or H W X S P T K on the message border;
                     drag the column border;
                     scroll bars (every window that needs one, and
                     this help): ▲ ▼ line, track page, drag the thumb;
                     the wheel scrolls the message, the lists and this
                     help (a key brings a list back to its selection)

Message list: N = new, A = answered, * = flagged, D = deleted,
@ = has an attachment (T on the message border is inverted then),
+ = selected
